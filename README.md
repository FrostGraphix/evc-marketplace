## ⚡ Architecture & Tech Stack

- **Framework**: Next.js App Router (TypeScript) with dynamic Server & Client components
- **Design System**: Tailored EVC Light & Dark Tokens
  - Dark background: strictly `#03090a`
  - EVC Orange Brand: `#f26522`
  - Glow Accent: `#ff7a33`
  - Deep Navy: `#0a1628`
  - Clean card outlines: `border border-glow/25 bg-gradient-to-br from-glow/20 to-brand/10`
- **Database & Auth**: Supabase PostgreSQL backend with Row Level Security (RLS)
- **Payment Processing**: Paystack Gateway (Naira Debit Cards, USSD, Apple Pay, Bank Transfers) with webhook automation
- **Logistics Engine**: 36-State + FCT logistics calculator with direct fulfillment routes for Ilorin, Ibadan, and Abuja corporate hubs
- **Omnichannel WhatsApp**: 24/7 direct consultation and quote routing to `+234 708 293 8870`
